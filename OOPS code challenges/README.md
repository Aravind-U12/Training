# Java Practice Problems

Ten independent, runnable Java console examples.

## Requirements
- JDK 8 or newer
- Windows CMD, PowerShell, VS Code terminal, or another terminal

## Run an example
1. Open a terminal in the required example folder.
2. Compile:
   `javac Main.java`
3. Run:
   `java Main`

Each example is self-contained in `Main.java` and uses package-private helper classes so it can be compiled with one command.

## Examples
1. Student class — encapsulation, constructors, validation, getters/setters.
2. Bank account — deposit, withdrawal, balance protection.
3. Employee management — ArrayList, add, search, list.
4. Vehicle inheritance — inheritance, `super`, overriding, polymorphism.
5. Shape area calculator — interface and polymorphism.
6. Shopping cart — composition, collections, quantities, totals.
7. Movie rating system — collections, validation, average rating.
8. Hospital patient records — Map-based registration and lookup.
9. School result processing — subject marks, total, average, pass/fail.
10. Online course management — enrollment and duplicate prevention.
